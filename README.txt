AEROYAAN Men's Footwear — starter storefront

Files:
- index.html: website
- images/product-1.jpg ... product-4.jpg: your uploaded product photos

Included:
- Responsive storefront, product filters, product sizes, cart saved in this browser
- ₹350 per pair for all four product cards
- Checkout form that prepares an order message for WhatsApp after the store number is configured

Important:
This is a static demo, not a complete production e-commerce backend. It does not process online payments, reserve inventory, securely store customer orders, calculate shipping, or provide admin order management. Before public selling, connect an e-commerce backend and an approved payment provider; add actual policies, business contact, shipping/returns details, and verify all sizes and product information.

To preview locally, open index.html in a browser. To publish on GitHub Pages, upload the whole contents of this folder to the repository root and enable Pages in repository Settings.
